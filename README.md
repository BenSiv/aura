# Aura: Real-World Resonance

A local-first, mesh-powered networking protocol designed for authentic human connection.

## Why Aura?

Aura is built to solve a fundamental crisis of our time:

- **Fighting the Loneliness Pandemic**: We use technology to break the digital barrier and facilitate real-world, face-to-face interactions.
- **Taking Back Control**: Reclaiming the power of connection from Big Tech algorithms and putting it back into the hands of the people.
- **Removing Conflicts of Interest**: Aura isn't designed for "engagement metrics." It’s a tool meant to get you off your phone and into a conversation.
- **Data Sovereignty**: Built on a secure, local-mesh network where your data remains yours, on your device, always.

For a deeper dive into our philosophy, read the [Aura Manifesto](./doc/MANIFESTO.md).

## Features

- **P2P Discovery**: Find people nearby using a decentralized libp2p mesh.
- **Resonance Matching**: Connect based on energy signatures and shared interests.
- **Secure Mesh Chat**: End-to-end encrypted messaging that works without internet infrastructure.
- **Privacy First**: Fully "Cloaked" mode for stealth discovery and secure data handling.

## Development

Aura is built with a cross-platform stack:
- **Core**: Rust (libp2p, SQLite, Tauri)
- **UI**: React + Vite (Natural Flow UI)
- **Mobile**: Android (via Tauri/Mobile)

### Getting Started

1. **Install Dependencies**: `make install`
2. **Run Dev Server**: `make run`
3. **Build Android APK**: `make build-local`
4. **Deploy to Device**: `make deploy`
